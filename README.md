# 🦫 Сапёр Бобёр 0.1

Первый визуальный прототип Telegram Mini App.

## Что уже работает

- Баланс 1000 виртуальных монет.
- Ставки 10 / 25 / 50 / 100 / 250 / 500 / 1000.
- Поле 5×5.
- 5 мин.
- Случайная генерация мин.
- Открытие клеток.
- Проигрыш при мине.
- Множитель.
- Забор выигрыша.
- Повторная игра.
- Нижняя навигация: Игра / Бонус / Рейтинг / Профиль.

## Запуск

Нужен Node.js 20.19+.

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite, обычно:

http://localhost:5173

## Сборка

```bash
npm run build
```

Готовая папка для статического хостинга:

`dist/`

## Важно

Это только клиентский прототип. Баланс и мины пока находятся в браузере.

Перед настоящим запуском в Telegram нужно вынести генерацию игры, баланс и расчёт выигрыша на сервер. Иначе игру можно будет подменить через браузер.

Следующий этап: Telegram Mini App + backend + PostgreSQL + авторизация через Telegram initData.
