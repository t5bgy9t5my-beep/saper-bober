# Сапёр Бобёр 0.2
Telegram Mini App prototype.

Добавлено: Telegram WebApp профиль, имя/фото/ID, сохранение виртуального баланса, ежедневный бонус +100, экраны игры/бонуса/рейтинга/профиля.

Важно: это всё ещё клиентский прототип. Баланс и бонус хранятся локально и не защищены. Перед любой экономикой с реальной ценностью нужен сервер, БД и проверка Telegram initData.
